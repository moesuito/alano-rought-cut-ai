# F1.1 — Timing, RNNoise, and EDL Boundary Refiner

**Requirement:** CUT-02  
**Difficulty:** 8/10  
**Layer:** Python / FFmpeg  
**Depends on:** harness baseline  
**File ownership:** `helpers/timing.py`, `helpers/audio_analysis.py`, `helpers/refine_edl_boundaries.py`, `helpers/models/**`, `tests/**`, `pyproject.toml` only when needed for tests.

## Goal

Implement the deterministic, in-place pre-export boundary refiner. It uses word-level source transcripts as semantic anchors, raw waveform analysis as the authority for connected speech, and mandatory RNNoise as an aligned corroborating signal. It must produce exportable source frame boundaries without rendering a preview or changing XML code yet.

## Required behavior

- Bundle `helpers/models/cb.rnnn` with SHA-256 `F1357C4E5BE9DEE8467BEAD486DFCED2D75B640C26AD0B594FA7F102322371D9`; include provenance and the source commit `3eee541a283fd3b8f81b85b1748e3b9ccbefa04d` in a local notice.
- Refuse to refine when the model hash is wrong, `arnndn` is unavailable, source media is missing, a transcript anchor is unavailable, the source is VFR, or the EDL has mixed rational FPS. Fatal failures return exit 1 and leave `edl.json` byte-for-byte unchanged.
- Use `Fraction` FPS parsing. In-points use `floor(onset * fps)`; out-points use `ceil(offset * fps) + 2`; `start/end` become their exact frame projections and ranges gain `source_in_frame/source_out_frame`.
- Build/cache raw and RNNoise mono PCM16/48k analysis audio under `<edit>/audio_analysis/`, fingerprinted by source metadata, model hash, parameters, and FFmpeg identity. No `loudnorm`.
- Detect activity with 10ms RMS / 5ms hop, local non-speech noise floor in ±5s, adaptive hysteresis, 40ms gap fill, 60ms transient protection, and raw/RNNoise lag compensation in ±30ms. Raw protection is limited to the component connected to the retained ASR word so breaths are not retained as speech.
- Classify high/medium/low exactly as the approved plan: high agreement/stability <=1 frame, medium <=2 frames without collision/clamp, otherwise low. High/medium endpoints apply; low endpoints stay original and set review status.
- Never cross a neighboring rejected word; a tail that cannot keep two frames is low rather than silently shortened.
- Before mutation, create a deduplicated backup at `<edit>/backups/edl.<full-input-sha256>.json`; write EDL and report atomically. The report path is supplied by `--report`, records input/output hashes, settings, source fingerprints, all boundary evidence, status, and confidence.
- CLI: `python helpers/refine_edl_boundaries.py <edl> --transcripts <dir> --report <path>`. Exit 0 = pass, 2 = review, 1 = fatal. Same output/configuration/source fingerprints must be idempotent.
