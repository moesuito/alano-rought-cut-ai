# F1.5 — Fail-Closed Pipeline And Rational XML Parity

**Status:** active  
**Depends on:** F1.4  
**Difficulty:** 7/10  
**Layer:** Python helpers / validation contracts  
**Requirements:** CUT-01, CUT-02, CUT-03

## Evidence

The private C022 run produced a 30 fps `preview_timeline.json` but a 24 fps `timeline.xml`. Its EDL had no refined frame fields, its boundary report used the legacy schema, and its preview transcript had `words: []`; `verify_edit_ready.py` nevertheless returned READY.

## In Scope

1. Make `verify_edit_ready.py` fail closed for the v0.4 automated workflow:
   - require the refiner report schema and `status: pass`;
   - require `output_edl_hash` to equal the current EDL SHA-256;
   - require integer `source_in_frame` / `source_out_frame` on every range, positive duration, and no `review_required` range;
   - consume preview transcript status from the actual report contract (including `summary.status`) rather than defaulting missing top-level state to pass;
   - reject missing or zero timed-word coverage.
2. Make preview transcript QC report word count, timed-word count, timing coverage, and a blocking status when timed words are absent. CI remains provider-mocked and never calls ElevenLabs.
3. Make renderer automated use require exact source frames. Preserve an explicit, noisy manual compatibility escape hatch only if needed; no silent fallback in the normal path.
4. Make XML rate/frame conversion use rational `metadata.sequence_fps` as the timeline authority, including WAV-only sources. Exact 24/25/30/60 must not be mislabeled NTSC; 24000/1001, 30000/1001, and 60000/1001 must retain NTSC semantics.
5. When refined frame fields exist, XML must copy them exactly and produce the same cumulative frame durations as the WAV timeline map. Manual XML CLI remains usable with QC warnings as specified by v0.4.
6. Add regression tests for the exact fail-open cases above.

## Out Of Scope

- Adaptive VAD component selection and cue-tail removal (F1.6).
- Calls to external transcription services.
- Private media mutation, push, merge, tag, release, or publication.

## Acceptance

- The old C022 artifact shape (legacy boundary report, missing range frames, empty timed words) cannot return READY.
- A WAV-source EDL with `sequence_fps: "30"` generates a 30/FALSE XML and preserves all provided source frames.
- Rational NTSC rates round-trip without float-based misclassification.
- Public tests, baseline validation, and diff checks pass.
