## Problem Contract

The C022 manual stint exposed three distinct entry failures: excess silence before speech, an entry inside the intended attack, and a rejected `Corta` tail before `manter`. A fixed trim or fixed pre-roll would trade one failure for another and is forbidden.

## In Scope

1. Replace first-active/last-active anchor selection with explicit connected-component candidates scored against the selected lexical anchor.
2. Compute start/end confidence independently and locally. One failed end sweep must not automatically invalidate an otherwise stable start, and vice versa.
3. Add a rejected-neighbor guard:
   - if the chosen activity component overlaps or is connected to a word outside the selected range, do not call it high/medium merely because raw and RNNoise agree;
   - for a recognized recording cue immediately before the intended first word, use the lexical first-word boundary plus raw attack evidence to exclude the cue tail while retaining less than one frame of attack guard;
   - if separation is not defensible, retain the original boundary, mark low/review, and stop automated export.
4. Record candidate components, selected component, neighbor collision, local SNR/correlation/sweep, guard milliseconds, and rejection reasons in the boundary report.
5. Extend preview audio QC per range/join: entry inactivity before stable speech, attack guard, residual pre-anchor activity, left tail, and current pop metrics. Use max-per-channel activity so antiphase stereo cannot cancel speech.
6. Extend preview transcript QC with EDL + source transcripts + timeline map:
   - timed preview words are mandatory;
   - compare the expected left suffix and right prefix at every join;
   - block unexpected 1–2 token prefixes/orphans, words crossing a join, missing/deformed first expected words, direction cues, and excessive entry silence;
   - keep global similarity/recall as supplemental evidence.
7. Add public synthetic tests for early silence, tight plosive/sibilant attack, rejected cue tail, breathing, legitimate pause/resumption, antiphase stereo, and empty/untimed transcripts.
8. Run the private C022 regression read-only from `D:\Antigravity\alano-cut\audio`, writing only to temp or a new ignored output directory. Preserve the rejected baseline for A/B.
