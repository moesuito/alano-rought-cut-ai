# F1.6 — Adaptive Lexical/Acoustic Boundaries

**Status:** completed
**Depends on:** F1.5
**Difficulty:** 8/10
**Layer:** Audio analysis / EDL boundary refinement
**Requirement:** CUT-02

## Problem Contract

The C022 stint exposed both directions of entry error: excess pre-roll and an attack cut too tightly. A rejected “Corta” tail is acoustically connected to the intended “manter”. A fixed trim or fixed pre-roll would trade one failure for another and is forbidden.

The current refiner also couples start/end threshold sweeps. On the real lesson, one missing detector at one edge makes every edge low-confidence even when the opposite edge is stable.

## In Scope

1. Resolve start and end independently. One failed end detector/sweep must not invalidate an otherwise stable start, and vice versa.
2. Preserve connected activity-component candidates and score them locally against the selected first/last lexical word instead of taking the first/last active bin blindly.
3. Add rejected-neighbor guarding:
   - calculate the previous/next rejected word frame limits;
   - report whether a candidate component overlaps a rejected word;
   - never call a colliding component high merely because raw and RNNoise agree;
   - when the previous rejected word is a generic recording cue such as “corta” and the intended first word begins in the same acoustic component, exclude the cue with a lexical frame guard while preserving less than one frame before the intended word;
   - for non-cue ambiguity that cannot be separated defensibly, retain the original limit and return low/review.
4. Add a lexical fallback for quiet anchor words missed by VAD. It may be medium only when the selected word timestamp is valid, later stable speech supports the phrase, local SNR/correlation are acceptable, and no rejected neighbor collides.
5. Protect endings conservatively:
   - never move an out-point before the selected last word;
   - prefer the later raw tail over an earlier RNNoise tail;
   - an original out-point may be medium lexical-safe when it contains the last word, excludes the next rejected word, and local acoustic evidence shows no clipping;
   - clamp/collision that cuts the selected word remains low/review.
6. Calculate SNR/correlation/sweep in local anchor windows and record per-side evidence: candidate components, selected component, lexical fallback, neighbor guard, collision, attack/tail guard milliseconds, local metrics, and rejection reasons.
7. Keep quantization frame-exact and deterministic. No global fixed trim, fade, or normalization.
8. Add public synthetic unit tests before implementation: early silence, quiet first word, tight plosive/sibilant, rejected cue connected to the anchor, ordinary rejected word ambiguity, breath/transient, independent start/end sweep, weak word tail, and exact neighbor-frame limits.
9. Run a private read-only C022 diagnostic using D:\Antigravity\alano-cut\audio; write only under pytest temp or a new ignored temp directory. Do not edit the existing rejected output.
