# F1.2 — WAV Preview, Timeline Map, and Join QC

**Requirement:** CUT-02
**Difficulty:** 7/10
**Layer:** Python / FFmpeg
**Depends on:** F1.1
**File ownership:** `helpers/render.py`, `helpers/preview_audio_qc.py`, `tests/**`, plus narrowly required shared timing imports.

## Goal

Replace the video preview pipeline with a dry, deterministic audio-only preview and reject dangerous joins before the workflow can reach XML.

## Required behavior

- `python helpers/render.py edit/edl.json -o edit/preview.wav --timeline-map edit/preview_timeline.json` renders PCM16, 48 kHz, stereo WAV (RF64 when required), with no video stream, AAC, x264, fades, RNNoise, loudnorm, compression, normalization, or `clips_preview/` directory.
- Reject `.mp4` output. Keep `--preview` and `--draft` as deprecated no-op compatibility flags for v0.4 only.
- Resolve every cut from `source_in_frame/source_out_frame` when present, otherwise the shared rational frame conversion. Source frame samples and cumulative output samples must be deterministic; source and output math must use the same shared timing module.
- Mono duplicates L/R, stereo preserves channels, multichannel downmix is explicit and documented in the timeline map.
- Create output through temporary PCM/WAV material and atomic replacement. Failure must not replace a valid preview or map.
- Map records EDL hash, output format/sample rate/channel policy, and each range's source frames, source sample interval, output cumulative sample interval, and seconds.
- Add `helpers/preview_audio_qc.py` producing `edit/preview_audio_qc.json`. It verifies WAV format, sample count/map parity (within one sample per join), leading silence, two-frame tail, speech clipping near boundaries, and join discontinuities.
- Severe pop is `max(0.10 FS, 8 * local p95 delta)`; warning is `max(0.05 FS, 4 * local p95 delta)`. Severe status requires review. Preserve report hashes and source/map binding.

## Out of scope

Semantic required beats, preview transcription, readiness gate, XML behavior, docs/release/installer, and private lesson media.

## Validation

Use public synthetic media only. Cover mono/stereo/anti-phase/multichannel policy, exact 23.976/25/29.97/30/59.94 frame-to-sample parity, no MP4/AAC/x264/fades, reject MP4, atomic failures, a clean join, and severe/warning discontinuities. Run focused pytest, compileall, and renderer/QC `--help`. Commit locally; never push or merge.
