# F1.4 — XML Parity, Audio-Only Workflow, and v0.4.0 Release Preparation

**Requirements:** CUT-01, CUT-04
**Difficulty:** 6/10
**Depends on:** F1.1, F1.2, F1.3
**File ownership:** XML helpers, workflow steps/docs, installer/version metadata, CI/tests only as required.

## Required behavior

- XML conversion consumes `source_in_frame/source_out_frame` preferentially and shares the rational timing core; XML and preview map must identify exactly the same source frames.
- `edl_to_fcpxml.py` remains usable manually and only warns when QC is missing/stale; it does not block. The normal Step 09 runs `verify_edit_ready.py` before XML.
- Replace normative preview references with `preview.wav`, `preview_timeline.json`, audio QC, semantic QC, and preview transcript QC. Remove fade/video inspection requirements. Keep `timeline_view.py` legacy and mark removal for v0.5.
- v0.4 docs/install/update/init include model/helpers, preserve old workspaces and legacy `preview.mp4` (ignored, not deleted), and do not introduce Node tooling.
- Bump project version to v0.4.0 and update README/changelog/protocols/install documentation.
- Add Windows CI checks that require FFmpeg `arnndn`, run public pytest with mock transcription only, and assert no MP4/AAC/x264/fade outputs in new workflow.
- Add opt-in private regression convention using `ALANOCUT_LESSON08_DIR` plus an ignored manifest; it must never read private media in public CI or commit private data.
