# Educacional / explicação

Use quando o material ensina uma ideia, conceito, framework ou lição, sem depender de um passo a passo operacional completo.

Estrutura comum: `TESE -> CONTEXTO -> EXPLICAÇÃO -> EXEMPLO -> TAKEAWAY`.

Priorize uma tese clara, somente o contexto necessário, explicação progressiva, exemplo que realmente esclareça e takeaway memorável.

Exclua definições repetidas, reformulações sem ganho, exemplos que confundam e tangentes que escondam a lição.

Riscos de revisão: abrir com contexto demais, remover o exemplo e deixar a ideia abstrata, ou comprimir as premissas necessárias. Preserve comprimento suficiente para compreensão e retenção.

Não force todos os beats quando a evidência não os sustenta.
